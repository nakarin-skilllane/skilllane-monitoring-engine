ชื่อหน้าจอ

หน้านี้ตอบคำถามอะไร ในหนึ่งประโยค · prod · 1 ชั่วโมงล่าสุด (13:20–14:20 ICT)

พื้นที่เนื้อหาของหน้าจอ

ใส่ section, panel, ตาราง และกราฟที่นี่ ตาม component ใน components.html และกติกาใน DESIGN.md

หมายเหตุการออกแบบ

วัตถุประสงค์

App shell อ้างอิงที่ทุกหน้าจอคัดลอกไปใช้ ไม่มีเนื้อหาจริง

ข้อมูลมาจาก

  • รายชื่อ env และ service: GET /api/meta
  • สถานะ ClickHouse ที่ท้าย sidebar: GET /api/health
  • เวลาข้อมูลล่าสุด: meta.now

การโต้ตอบ

  • env และช่วงเวลาเปลี่ยนทุก block ในหน้าพร้อมกัน และอยู่ใน URL (env, from, to)
  • ช่องค้นหา: trace id 32 ตัวอักษรเปิด trace-detail, u_… เปิด Log กรองตาม user, อย่างอื่นค้นใน Log; กด / เพื่อโฟกัส
  • จอแคบกว่า 900 px: sidebar ซ่อน เปิดด้วยปุ่มเมนู (focus ไปที่หน้าปัจจุบันในเมนู) ปิดด้วยปุ่ม × บนสุดของเมนู, Esc หรือแตะพื้นหลัง แล้ว focus กลับไปที่ปุ่มเมนู

คำถามที่ยังเปิดอยู่

  • เมื่อเลือก env "ทั้งหมด" (ไม่ส่ง env) ต้องมีปุ่มที่สี่ใน env switcher หรือไม่
