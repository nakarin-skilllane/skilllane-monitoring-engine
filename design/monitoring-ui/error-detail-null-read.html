หน้าของ error group 2 ซึ่งเป็นเรื่องหลักของ demo หลัง deploy: เกิดหลัง 31.4.0 เท่านั้น ใช้ layout เดียวกับ error-detail.html (group 1) เพิ่ม callout ว่าใหม่ใน version นี้, KPI ครั้งแรกแบบเตือน, กราฟต่อนาทีของชั่วโมงล่าสุด และตาราง version ที่ 31.3.2 เป็น 0 · ลิงก์ไปหน้านี้มาจาก callout ในภาพรวม, แถว route, รายการ error group, หน้า Error, Log และ Trace

ข้อมูลมาจาก

  • ทั้งหน้า: GET /api/errors/:fingerprint?env=prod&from=now-24h (endpoint เดียวกับ group 1) · NEW = group.isNew (firstSeenVersion = 31.4.0, SPEC §12 C)
  • callout และตาราง Version: versions ของ /api/errors/:fingerprint และ /api/meta deploys · ค่าก่อน deploy ของ route: /api/overview ช่วง 07:00–08:00 แบบเดียวกับคอลัมน์ Δ ในภาพรวม
  • กราฟรายชั่วโมง: series รวมเป็นชั่วโมงที่ :20 · กราฟต่อนาที: เรียก /api/errors/:fingerprint?from=now-1h (step 1 นาที) ตัวเลขตรงกับ 5xx ต่อนาทีของ route นี้ในภาพรวม
  • failedStep ว่างจึงแสดง – พร้อมเหตุผล · target = school และ fix บอกชื่อ entity ที่เกี่ยวข้อง
  • ครั้งล่าสุด: recent (LogRow) เหมือน group 1; trace id 3 ตัวแรกตรงกับหน้า Log และ Trace ที่เหลือเป็นค่าสมมติ · fingerprint, เลขบรรทัดใน stack และ hint detail เป็นค่าตัวอย่าง
