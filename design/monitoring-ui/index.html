skilllane monitor คืออะไร

App ที่ติดตั้ง skilllane-monitoring เขียน log และสร้าง trace ตามปกติ SDK ส่งข้อมูลเข้า queue ที่ลูกค้าใช้อยู่แล้ว เลือกได้ระหว่าง Kafka, RabbitMQ หรือ BullMQ skilllane-monitoring engine subscribe จาก queue นั้น เขียนลง ClickHouse แล้วเปิด query API ให้หน้าจอนี้อ่าน เราทำหน้าที่ publish และ subscribe เท่านั้น ไม่ได้ดูแล queue ของลูกค้า

ทุกหน้าจออ่านจาก engine API (/api/*) เท่านั้น และทุกหน้าใช้ข้อมูลตัวอย่างชุดเดียวกัน: env prod, หลัง deploy school-core-api 31.4.0 เมื่อ 08:00 (ก่อนหน้า 31.3.2)

ภาพ ข้อมูลเดินทางอย่างไร ด้านล่างเล่นเส้นทางนี้ทีละขั้น: log และ span ออกจากแอปเป็นชุด พักใน queue ไปที่ engine ลง ClickHouse แล้วหน้าจอนี้และ AI อ่านต่อ

สิ่งที่หน้าจอต้องทำให้เห็นชัด

  1. 1ใช้ได้กับทุก app ที่ติดตั้ง packageservice / role / env อยู่ในทุกแถวและทุกหัวข้อ
  2. 2Log กิจกรรมพร้อมเวลาLog: ค้นหา กรอง histogram ตาม level
  3. 3Trace ราย requestTrace และ trace detail: waterfall ข้าม service
  4. 4เป็นมิตรกับ AIคัดลอกให้ AI, ชื่อ field คงที่, ลิงก์พจนานุกรมข้อมูล
  5. 5Error อ่านง่ายและบอกที่แก้Error และ error detail: hint, fix, function, ไฟล์, target, หมวด

หลักการออกแบบ

  1. ข้อมูลมาก่อน

    ตัวเลข เวลา และ id อยู่ตำแหน่งแรกที่สายตาไปถึง ไม่มี hero ไม่มีภาพประกอบ ทุก block บอกช่วงเวลาและ env ที่มันแสดง

  2. สีหนึ่งสีมีความหมายเดียว

    แดง อำพัน เขียว ฟ้า ใช้กับสถานะเท่านั้น เขียวเข้มของ SkillLane คือสิ่งที่คลิกได้ ส้มคือปุ่มที่สำคัญที่สุดของหน้า สี service บอกตัวตน และทุกสีมีตัวอักษรหรือไอคอนกำกับ (สถานะเขียวมีจุดหรือไอคอนเสมอ)

  3. Error ต้องบอกที่แก้

    หัวข้อคือ hint ตามด้วยประโยค fix, function, ไฟล์ และ target ส่วนข้อความ error ดิบอยู่บรรทัดถัดไป ไม่ใช่หัวข้อ

  4. ทุกแถวมีบริบท

    service / role / env และเวลา ICT อยู่ในทุกแถว เพื่อให้ใช้ได้กับทุก app ที่ติดตั้ง package และไม่ต้องเดาว่าดูของใครอยู่

  5. คัดลอกได้ทุกอย่าง

    trace id, user id, stack และสรุป Markdown สำหรับ AI คัดลอกได้ในคลิกเดียว ชื่อ field ตรงกับ ClickHouse และพจนานุกรมข้อมูล

  6. ใช้ตอนตีสองได้

    dark theme ออกแบบเท่ากับ light ไม่มีพื้นที่สว่างจ้า ตัวหนังสือไม่เล็กกว่า 11 px · animation บอกแค่ว่าอะไรเพิ่งเข้ามา เปลี่ยน หรือเกิดก่อนหลัง จบใน 0.7 วินาที และปิดเองเมื่อเครื่องตั้ง reduced motion
