การโต้ตอบ

  • แผนที่ระบบ: ป้ายของจุดที่ปกติแสดงแค่ชื่อ (compactLabels) เพราะกล่องเล็ก ตัวเลขอยู่ใน tooltip และในตาราง · ชี้หรือ focus แถวในตารางสุขภาพ service หรือ Dependency: จุดเดียวกันในภาพสว่างขึ้นพร้อมจุดที่เชื่อมกัน ส่วนจุดและป้ายอื่นจางลง · ชี้จุดหรือป้ายในภาพ: แถวของมันในตารางสว่างขึ้นและมี tooltip ครบทุกค่า · กดป้าย: เปิดหน้าที่เกี่ยวข้อง · ลากเพื่อหมุน ปุ่ม + − รีเซ็ต หยุด · "ขยาย": ภาพเต็มความกว้าง 540 px และป้ายแสดงตัวเลขครบ · จอแคบกว่า 1280 px ภาพอยู่ใต้ตารางสุขภาพ service
  • Motion: เส้นกราฟวาดจากซ้ายไปขวา แท่ง 5xx โตจากแกน จุดค่าล่าสุดมีวงกระเพื่อม 3 ครั้งแล้วหยุด (= นาทีปัจจุบัน ไม่วนตลอด) · sparkline ในตาราง service วาดเมื่อเลื่อนมาเห็น จุดท้ายเป็นสีเทาเข้ม ไม่ใช่สีเขียว (เขียว = SkillLane / กดได้ หรือ ปกติ)
  • ปุ่มใน "ต้องดูตอนนี้" เปิด error-detail ของ group นั้น, Trace (กรอง route + minMs) และ dependency ในหน้างานเบื้องหลัง · trace id ในข้อความเปิด trace นั้นตรง ๆ
  • กดแถว service: เปลี่ยน service ของกราฟและตาราง route (sync กับ select และ URL service, role); กดชื่อ service: เปิด Log กรองตาม service/role
  • ชี้หรือ focus บนกราฟ: tooltip แสดง request, 5xx (แยก route) และ p95 ของนาทีนั้นพร้อมกัน · กดหนึ่งนาที: เปิด Log ช่วงนาทีนั้น · "ดูเป็นตาราง" มีทุกค่า · จอแคบกราฟเลื่อนไปนาทีล่าสุดก่อน
  • กดชื่อ route: เปิด Trace กรอง route นั้น (route=METHOD /path) · ลูกศรขยายแถว route ที่ช้าหรือ error สูง
  • ชื่อ error group: group 1 และ 2 เปิดหน้า error-detail ของตัวเอง group อื่นเลื่อนไปแถวของมันใน errors.html · dependency และ queue เปิดหน้างานเบื้องหลังที่แถวนั้น
  • จอแคบกว่า 600 px: ตารางสุขภาพและ route เปลี่ยนเป็นแถวละ 2–3 บรรทัด (ซ่อน ประเภท, 60 นาที, 4xx, p50) เพื่อให้ error rate และ p95 อยู่ในจอเสมอ
  • หน้านี้ refresh ทุก 30 วินาที (ตาม meta.now ท้าย sidebar) โดยค้างภาพเดิมไว้ ไม่กระพริบ
