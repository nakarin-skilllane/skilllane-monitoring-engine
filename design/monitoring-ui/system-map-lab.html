การโต้ตอบ

        
    
          
  • ลากเพื่อหมุน (บนมือถือ ลากแนวนอน; ปัดแนวตั้งยังเลื่อนหน้าได้), ปุ่ม + − ซูม (ล้อเมาส์ไม่ซูม), ปุ่มรีเซ็ตมุมมอง, ปุ่มหยุดการเคลื่อนไหว
    • 
          
  • ชี้ที่อาคารหรือป้ายชื่อ: tooltip (req/min, error %, p95, การเรียกออก); คลิก: เปิดหน้าที่เกี่ยวข้อง; ปุ่มลูกศรบนภาพหมุน, + − ซูม, 0 รีเซ็ต
    • 
          
  • prefers-reduced-motion หรือ ?motion=off: ภาพนิ่ง เส้นประแทนจุดวิ่ง; ภาพอยู่นอกจอหรือแท็บถูกซ่อน: หยุดวาด
